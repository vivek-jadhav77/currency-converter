# 💱 Currency Converter

A real-time currency converter web application built using HTML, CSS, and JavaScript.  
The application fetches live exchange rates from an external API and dynamically converts currencies with accurate results.

---

## 🚀 Features

- 🌍 Live exchange rates using API  
- 🔄 Dynamic currency dropdown population  
- 🏳️ Automatic country flag updates  
- ⚡ Asynchronous data fetching using async/await  
- 🛑 Error handling for API failures  
- 🎨 Clean and responsive user interface  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Exchange Rate API

## 💡 Conversion Logic

The application uses a universal currency conversion formula:

convertedAmount = (amount / fromRate) * toRate

This ensures accurate conversion between any two selected currencies.
